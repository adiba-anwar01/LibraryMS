# 📚 Library Management System

A modern **Role-Based Library Management System** built using **React, Vite, and Firebase**. The application provides dedicated dashboards for **Admins**, **Staff Members**, and **Library Members** to streamline and automate library operations.

---

## 🌐 Live Demo

🔗 https://library-ms-nine-mu.vercel.app

---

## ✨ Features

### 👑 Admin Dashboard
- ⚙️ Manage library settings
- 👨‍💼 Create and manage staff accounts
- 💰 Configure fine per day for late returns
- 📅 Configure book return duration
- 📊 Monitor overall library operations

### 📖 Staff Dashboard
- ➕ Add new books
- ✏️ Update book details
- 🗑️ Remove books from inventory
- 📚 Issue books to members
- 🔄 Process book returns
- 📋 Track issued books and library records
- ✅ Manage book availability

### 👤 Member Dashboard
- 🔍 Browse available books
- 📝 Request book issuance
- 📚 View issued books
- 🔄 Return borrowed books
- 💸 Check pending fines
- 📈 Monitor borrowing status

## 🛠️ Tech Stack

- ⚛️ React
- ⚡ Vite
- 🔥 Firebase Authentication
- 🗄️ Firebase Firestore
- 🎨 CSS


## 👥 User Roles

### 👑 Admin
Responsible for library configuration, staff management, and system settings.

### 📖 Staff
Responsible for managing books, issuing books, processing returns, and maintaining records.

### 👤 Member
Can browse books, request book issues, return books, and monitor fines.
